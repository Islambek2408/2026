# 🚀 O'rnatish Qo'llanmasi

## ✅ Talablar

- Python 3.8+ 
- Git
- pip (Python package manager)
- 50 MB free disk space

## 📋 O'rnatish Qadamlari

### 1️⃣ Git o'rnatish (agar o'rnatilmagan bo'lsa)

**Windows:**
- [git-scm.com](https://git-scm.com/download/win) dan yuklab oling
- Installer-ni bajaring
- Terminal qayta oching

**Mac:**
```bash
brew install git
```

**Linux:**
```bash
sudo apt-get install git
```

### 2️⃣ Loyihani klonlash

```bash
git clone https://github.com/Islambek2408/2026.git
cd 2026
```

### 3️⃣ Virtual Environment yaratish

**Windows:**
```cmd
python -m venv venv
venv\Scripts\activate
```

**Mac/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

✅ Ko'rinish: `(venv)` qo'shilishi kerak

### 4️⃣ Kutubxonalarni o'rnatish

```bash
pip install -r requirements.txt
```

⏳ 1-2 daqiqa vaqt oladi...

### 5️⃣ Ilovasini ishga tushirish

```bash
streamlit run app.py
```

✅ Browser ochiladi: `http://localhost:8501`
